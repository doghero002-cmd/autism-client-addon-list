## Related/out of date projects (now part of the client)

[doghero002-cmd/baritone](https://github.com/doghero002-cmd/baritone) is a customized Baritone fork described as supporting addon compatibility. It is listed separately because it is not an AUTISM Client addon itself.

[Liquidify-sskid3x/autism-client-addonsupport](https://github.com/Liquidify-sskid3x/autism-client-addonsupport) is an addon-development kit containing client/API code and an example addon, rather than a standalone addon entry.

## Scope

This list covers public repositories found on the creator profiles linked in this directory. Base clients and unrelated projects, including Meteor-only addons, are excluded. Repositories and descriptions can change; check each project's README for current compatibility and usage details. Some addons automate gameplay or change what is visible, so check the rules of any server before using them.
